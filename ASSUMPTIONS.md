# Assumptions registry

Every modelling judgement call has an ID. The same ID appears as a `[A-xx]`
tag in the code at the exact place it is applied, so `grep -rn "A-07" ponies/`
takes you straight there. `tests/test_assumptions_registry.py` fails if the
code and this table drift apart.

**Changing an assumption:** edit the constant in `ponies/config.py` (if it has
one), update the row below, re-run `python -m ponies.pipeline`, and record
the before/after backtest numbers in the *Change log* at the bottom.

| ID | Assumption | Where applied | Config key | Why / risk |
|----|-----------|---------------|------------|------------|
| A-01 | Recent form = the horse's last **3** starts | `features._runner_features` | `RECENT_STARTS` | Balances recency against noise. Could try 4–5 or recency-weighted averages. |
| A-02 | Jockey/trainer win rates use a trailing **365-day** window | `features._WindowCounter.rate` | `CONNECTIONS_WINDOW_DAYS` | Captures current form of the connections; shorter windows are noisier. |
| A-03 | Win rates shrunk to prior **0.11** with weight **20** pseudo-starts | `features._shrunk_rate` | `PRIOR_WIN_RATE`, `PRIOR_RIDES` | Stops tiny samples (1/2 = 50%) dominating. Prior ≈ 1 / typical field size. |
| A-04 | "Similar distance" = within **±1 furlong** | `features._runner_features` (`distance_fit`) | `DISTANCE_TOLERANCE_FURLONGS` | Sprint vs route matters; exact-distance matching would leave too little data. |
| A-05 | Track conditions collapse to **wet / dry** (wet = sloppy, muddy, wet fast, heavy, soft, yielding, good) | `features._cond_group` | `WET_CONDITIONS` | "good" is treated as wet, a judgement call. Turf firm counts as dry. |
| A-06 | Layoff days capped at **365** before `log` | `features._runner_features` (`log_layoff`) | `MAX_LAYOFF_DAYS` | Diminishing difference beyond a year. The effect is learned linearly in log days; real effect is likely U-shaped (too fresh / too stale). |
| A-07 | Missing features are imputed with the **median of the runner's own race field** (training-set mean if the whole field lacks the value), plus a `has_history` flag | `model.ConditionalLogit._prepare`, `figure_model.SpeedFigureModel._prepare`, `features.FEATURES` | `IMPUTE_STRATEGY` | A debut horse is treated as "average for this race". This works on any figure scale, so a model trained on one data source isn't thrown off by another source's numbers. It used to be the training mean, which made debut horses look best in races on lower figure scales. |
| A-08 | Chronological split: the **latest 20 %** of races are the test set | `pipeline.chronological_split`, `evaluate` | `TEST_FRACTION` | Avoids training on the future. A rolling/walk-forward backtest would be more robust. |
| A-09 | L2 penalty **0.01** on standardised weights | `model.ConditionalLogit.fit` | `L2_PENALTY` | Mild regularisation; not tuned. Tune by cross-validation on the training period. |
| A-10 | Full-batch gradient descent, lr **0.5** (halved on overshoot), ≤ 2000 iterations, tol 1e-7 | `model.ConditionalLogit.fit` | `LEARNING_RATE`, `MAX_ITERATIONS`, `TOLERANCE` | The loss is convex, so the optimum is unique; these only affect speed and precision. |
| A-11 | Market odds are **not** a model input by default | `features.FEATURES`, `features._runner_features` | `USE_MORNING_LINE_FEATURE` | Keeps the model an independent opinion to compare with the odds. Benter-style blending (model + market) usually scores better; flip the flag to try. |
| A-12 | Implied probabilities from odds are **normalised to sum to 1** per race | `odds.implied_probabilities`, `evaluate` | `NORMALISE_IMPLIED_PROBS` | Removes the takeout. Proportional normalisation ignores the favourite–longshot bias. |
| A-13 | "Value" = model_prob × decimal M/L odds − 1 > **0.10** | `pipeline.race_cards`, `evaluate.evaluate` | `VALUE_EDGE_THRESHOLD` | Dashboard uses **morning line** (known before the race); backtest uses **final** odds. |
| A-14 | Backtest bets are flat **1 unit** at **final odds**, ignoring the odds moving because of our own bets | `evaluate._roi` | `FLAT_STAKE` | Final odds aren't known when you bet, so backtest ROI is optimistic. |
| A-15 | Calibration uses **10** equal-width probability bins | `evaluate.calibration_table` | `CALIBRATION_BINS` | Display only. |
| A-16 | Dead heats: co-winners **split** the win target equally | `model.win_targets` | – | Standard treatment; dead heats are rare. |
| A-17 | Fit features (distance/surface/condition) are **0** when the horse has figures but none under today's condition; **missing** when it has no figures at all | `features._fit` | – | "No evidence" is treated as neutral rather than negative. |
| A-18 | Unknown post position → **middle** of the field (0.5); unknown weight → **race average** | `features._runner_features`, `features.build_features` | – | Neutral defaults. |
| A-19 | Live predictions use a model **refit on all history** (the backtest model is trained on the training split only) | `pipeline.run` | – | Uses the latest form. The reported backtest therefore describes a slightly different (less-trained) model. |
| A-20 | If a start appears in both a result chart and a PP file, the **result chart wins** | `xml_io.load_history` | – | Result charts are the official record. Matching is by `race_id` + `horse_id`, so IDs must be consistent across files. |
| A-21 | **Scratched** runners are dropped and not counted in `field_size` | `xml_io.parse_card` | – | They didn't run. |
| A-22 | Runners with **no prior starts** in the data are never flagged as value bets, and the dashboard labels them "no form data" | `pipeline.race_cards` | – | Their features are imputed as average [A-07], which can make a debut horse at long odds look like a huge edge. |
| A-23 | TrackMaster IDs: horses = name + foaling date; jockeys and trainers = display name | `trackmaster.horse_id`, `trackmaster.person_id` | – | The file has no horse key, and its PP lines have no jockey key. Two jockeys with the same display name would be merged. |
| A-24 | TrackMaster units: distance unit F = hundredths of a furlong, Y = yards, M = metres; age = race year − foaling year | `trackmaster._furlongs`, `trackmaster._age` | – | Checked against `dist_disp` ("1M" = 800.0 F, "350Y" = 350 Y, "6F*" = 1200 M). Ages follow the North American 1 January birthday rule. |
| A-25 | TrackMaster PP lines with field size 0 or finish 0 are skipped, and speed figure 0 means missing | `trackmaster._pp_row` | – | These lines aren't races: they have no finish, odds or figure. |
| A-26 | Speed-figure model = **ridge regression** (penalty **0.05** on standardised features) predicting a start's speed figure from the horse's earlier starts | `figure_model.SpeedFigureModel.fit` | `FIGURE_RIDGE` | Linear and fast enough to train in the browser. Training examples are single starts, so it needs no complete fields. |
| A-27 | "Sprint" = under **7.5 furlongs**; a sprint↔route switch is a feature | `figure_model._row_features` | `SPRINT_MAX_FURLONGS` | The US convention is roughly sprints < 1 mile. |
| A-28 | Predicted-figure uncertainty σ = residual standard deviation for horses with **0, 1–2, 3–5 or 6+** prior starts | `figure_model._bucket`, `SpeedFigureModel.fit` | `FIGURE_SIGMA_BUCKETS` | Lightly raced horses are less predictable. Buckets with fewer than 10 examples use the overall σ. |
| A-29 | Win probability = share of **20,000** simulated races won, each horse's figure drawn from N(predicted, σ), with fixed seed **0** | `figure_model.SpeedFigureModel.predict_proba` | `SIMULATIONS`, `SIMULATION_SEED` | Treats horses as independent, with no pace interaction. The fixed seed makes browser and pipeline results identical. |
| A-30 | Model per card: TrackMaster cards → speed-figure model trained **only on that source's PP lines** (in the browser: the uploaded file's); other cards → whichever model has the lower backtest log loss | `pipeline.run`, `browser.predict_card` | `WIN_MODEL` | Figure scales never mix between sources. A TrackMaster file with fewer than 20 figured starts falls back to the exported model. |
| A-31 | Speed figures are compared only **within a group**: Thoroughbred flat (TB), Thoroughbred **jump** races (TB-JUMP: TrackMaster course codes M, B, S) and Quarter Horse (QH, including mixed-breed "MX" races). One speed-figure model is trained per group, and each race uses its own group's model, built from that group's lines | `trackmaster.breed_group`, `trackmaster.JUMP_COURSES`, `pipeline.trackmaster_cards` | – | QH figures use the AQHA scale, and jump-race figures sit far below flat figures, so neither is comparable with Thoroughbred flat figures. MX races are run at QH distances. |
| A-32 | **Head-to-head check:** every pair of runners from the same unseen past race. Did the horse that finished ahead get the higher predicted figure? Compared with the market (lower final odds) and with "average of last 3". Pairwise log loss uses P = Φ(Δμ / √(σa² + σb²)) | `figure_model.head_to_head` | – | Past-performance files rarely contain complete fields, but they contain many pairs, so this is the real-outcome test available without results charts. Pairs only include horses that raced again, a mild selection bias. |
| A-33 | Speed-figure-model inputs are capped at **±4 standard deviations** | `figure_model.SpeedFigureModel._prepare` | `FEATURE_CLIP_SD` | One odd value (a foreign line, a huge distance or weight change) shouldn't create an extreme prediction. It slightly improved head-to-head log loss on real data. |
| A-34 | Uncertainty σ is multiplied by a **temperature** chosen (from 0.5 to 6) to minimise head-to-head log loss on the unseen later starts. It stays 1 below 100 pairs | `figure_model.calibrate_temperature`, `fit_with_holdout` | `TEMPERATURE_GRID`, `MIN_CALIBRATION_PAIRS` | On 32 real cards Thoroughbreds needed about 3, because extreme picks were overconfident, while Quarter Horses needed about 1. It is tuned on the same pairs it is reported on, so the calibrated head-to-head number is slightly optimistic. |
| A-35 | **Value-bet ★ only when the probabilities shown beat the market at picking winners**: on unseen winner-vs-rival pairs, their log loss must be lower than the market's by **more than 2 standard errors**. The conditional logit uses race log loss instead. Otherwise the page says why flags are off | `pipeline.value_flags_allowed`, `figure_model.head_to_head` | – | Ordering the whole field better isn't enough. On 32 real cards the blend beat the market on all pairs (0.631 vs 0.654) but not on winner pairs (0.573 vs 0.574), and an all-pairs rule produced 187 long-shot "value" bets. |
| A-36 | **Speed figures from races outside the USA, Canada and Puerto Rico are ignored.** Those starts still count for experience and layoff, and `abroad_recent` (the share of the last 3 starts run abroad) is an input | `trackmaster._pp_row`, `figure_model._row_features` | `trackmaster.DOMESTIC_COUNTRIES` | In 32 real cards foreign Thoroughbred figures averaged 75 vs 69 domestic (winners 90 vs 79), so they're on a higher scale. Without this, imports with foreign form were over-rated. |
| A-37 | **Model + market blend** (Benter 1994): score = *a* × expected figure + *b* × log(market win probability), softmax within the race. *a* and *b* are learned by logistic regression (no intercept) on **winner-vs-rival pairs** from slice B, using the A-model's predictions, and scored on slice C | `figure_model.fit_blend`, `_blend_design`, `fit_with_holdout`, `SpeedFigureModel.predict_proba` | `BLEND_MARKET_COLUMN` | Training on all pairs answered "who finishes ahead", which the market is weak at among also-rans, and gave b ≈ 0.65, inflating longshots. Winner pairs answer "who wins". With fewer than 100 winner pairs no blend is fitted. |
| A-38 | Blend weights are learned with **final odds** (all that past-performance lines record) but applied to **morning-line odds** for upcoming races. A runner with no odds gets the race median; a race with no odds at all uses the model alone | `figure_model.SpeedFigureModel.predict_proba` | `BLEND_MARKET_COLUMN` | The morning line is noisier than final odds, so the blend leans a little too much on the market. That is conservative: fewer value bets, not more. |
| A-39 | FormFav has no surface field: Polytrack, synthetic or Tapeta in the track name or rating → synthetic, otherwise turf | `formfav.surface_for` | – | Almost all Australian racing is on turf. |
| A-40 | FormFav form strings read oldest → newest. "X" marks a spell (ends in X = first-up; X then one run = second-up), and "0" = 10th or worse (counted as 10) | `formfav.spell_status`, `formfav.finishes` | – | Matches the published cards: Satoshi "0X367" ran 3rd, 6th, 7th after a spell. |
| A-41 | Trainer and jockey win rates at the track come from FormFav's notes ("22% trainer win rate here (37 starts)"). They're missing when FormFav doesn't show the note, i.e. when the rate isn't notable | `formfav._decorator_rate` | – | FormFav only shows strong records, so a missing value isn't neutral. The model sees it as missing and imputes [A-07]. |
| A-42 | FormFav pre-race market price = **median across bookmakers of each one's last fixed-odds price before the scheduled start**, replayed from the price-movement history, or the current price for races not yet run. It's stored in `morning_line`, so value flags compare against a price you could have bet | `formfav.market_odds`, `formfav._quote_before`, `formfav.race_rows` | – | FormFav's `close` field can be an in-running or post-race quote (seen: 451 for a beaten horse a minute after the start, and winners shortening after the jump), which would leak the result into the "market". Until 2026-10-24 `close` was used, so earlier market log losses were slightly optimistic. Median resists one bookmaker's outlier. Tote prices are excluded because they keep moving until the jump. |
| A-43 | **Price move** = log(opening price / closing price), both medians across bookmakers' fixed odds; positive means the horse firmed. It's an input to the market blend, not to the form model. For upcoming races it's open → current price, since the move isn't finished yet | `formfav.market_open`, `formfav.race_rows`, `scripts/formfav_train.py` | – | Late money is known to carry information beyond the final price (horses that firm tend to win more often than their final price implies). The blend learns its weight on slice B and is scored on C. |
| A-44 | **Best price** = the highest fixed price across bookmakers before the start (same replay as A-42). Betting simulations settle at it, because a bettor who shops around gets it | `formfav.market_best`, `scripts/formfav_experiments.py` | – | With 4–6 bookmakers the best price is typically several percent above the median. A single stale quote can make it too generous, so results at the median price are reported too. |
| A-45 | Candidate card inputs (place rates by distance/track/condition, track+distance win rate, peak-rating gap, best class won vs today's class, runs this preparation, best and 6-run average recent finish, FormFav note sentiment and note types, leader running style) are computed for every runner but used only after the walk-forward comparison shows they help | `formfav.extra_features` | – | Keeps the production model to inputs with evidence behind them. |
| A-46 | **Previous run in the store**: lengths beaten, the market's view then (log of field size × implied win probability; 0 = an average chance), whether it won, and days since. Only runs on earlier dates count; missing when the horse hasn't run within the stored window | `formfav.add_store_history` | – | FormFav cards give finishing positions but not margins or past prices, and those carry information. Coverage grows as the store grows (30-day window at first). |
| A-47 | **FormFav's own predictions** (`get_predictions`, win probabilities from their ML model) are an input only when their `predictedAt` is before the race's scheduled start; otherwise they're treated as missing. Runners FormFav didn't predict are missing too | `formfav.formfav_predictions`, `formfav.race_rows` | – | Checked on Mornington R3 2026-10-22: predicted at 21:33 UTC the evening before a 05:00 UTC start. A prediction remade after the race would know the result. |
| A-48 | Tote dividends come from **one operator and jurisdiction per race** (the first one FormFav lists), per $1 and for winning combinations only | `formfav.load_dividends` | – | VIC, NSW and QLD pools pay different dividends; mixing them would let a backtest pick the best one after the fact. |
| A-49 | **Finishing order** from win probabilities: Harville with discounts (Lo & Bacon-Shone 1994): P(k 2nd given j 1st) ∝ p_k^λ2, P(i 3rd given j, k) ∝ p_i^λ3. λ2 and λ3 (grid 0.5–1.3) are fitted on earlier days' actual 2nd and 3rd places | `exotics.order_probs`, `exotics.fit_lambdas` | `exotics.LAMBDA_GRID` | Plain Harville (λ = 1) is known to overrate favourites for 2nd and 3rd. Gives place, quinella, exacta and trifecta probabilities. |
| A-50 | **Bets beyond the winner.** Place terms are 3 places with 8+ starters, 2 with 5–7, and none below 5. The expected dividend of a combination, if it comes in, = exp(a + b·log(market probability of that combination) + c·log(field size) + σ²/2), fitted per pool on earlier days' winning dividends. Value bet = model probability × expected dividend > 1 + threshold, settled at the actual dividend | `exotics.places_paid`, `scripts/formfav_bets.py` | – | Tote dividends are only known after the race, so the expected dividend has to be predicted. The regression on winning combinations is exactly E[dividend given it wins]. The market probability uses bookmaker fixed odds, so value appears where tote punters price combinations differently from the bookmakers. |
| A-51 | **Removing the bookmaker's margin**, three ways compared: proportional (1/odds rescaled, the default [A-12]), **Shin** (1993: margin falls more on longshots, z solved so the probabilities sum to 1) and **power** (1/odds raised to k ≥ 1) | `odds.shin_probabilities`, `odds.power_probabilities`, `scripts/formfav_experiments.py` | – | Our races showed the favourite–longshot bias (3rd favourite won 13.2% at a typical $6.00 = 16.7% implied), which proportional removal ignores. |
| A-52 | **Where the bias may differ**: wet tracks (soft/heavy), maiden races, big fields (12+), small fields (≤7), and price bands (favourite, 2nd, 3rd favourite, $10–20, $20+). The win model can learn a separate market weight per segment and an offset per band; the calibration table reports actual strike rate vs implied chance and the best-price return per band and segment | `scripts/formfav_experiments.py` (`SEGMENT_TERMS`, `BAND_TERMS`), `scripts/formfav_rank_bets.py` (`calibration`) | – | A cell only counts as value if its return is more than 2 SE above zero in both halves of the period, because about 40 cells are tested and some will look good by chance. |
| A-53 | **Betfair pre-race price** = each runner's last traded price before the market first turned in-play (or before the scheduled start if it never did); also the last traded price 30 minutes before the start, and the Betfair SP when the file has one. Removed (scratched) runners are dropped | `betfair.parse_market` | – | In-play trades (1.01 for a horse that's clear, 200 for one that's beaten) know the result. The Basic plan gives last-traded prices at one-minute intervals, not the full order book, so the pre-race price can be up to a minute old. |
| A-54 | **Exchange settlement**: 1-unit back bets pay (price − 1) × (1 − commission) when they win, −1 when they lose; commission defaults to **8%** (`--commission`) | `betfair.net_return`, `scripts/betfair_backtest.py` | – | Betfair charges commission on net winnings only. Rates vary by account and market (Australian racing is often 6–10%), so set your own. |

## Known limitations / ideas for whoever improves this next

* Speed figures are used as supplied. Figures from different vendors aren't comparable; pick one source.
* No pace or running-style features (early speed, closers), no pedigree, no workouts, no equipment or medication changes.
* Linear-in-features model. Next steps: interactions, a gradient-boosted ranker, or Benter's two-stage model (fundamental model, then blend with log market probability).
* A single train/test split for the TrackMaster models. FormFav models are compared walk-forward (`scripts/formfav_experiments.py`, re-run after every scheduled collection).
* FormFav (2026-10-24): no tested combination of card features beats the pre-jump bookmaker market. Detecting a real gain of 0.01 per race needs roughly 3,000 test races (the SE is about 0.17/√races). The store adds about 45 races a day. Information the market may not fully price, such as sectional times, trials, gear changes or stewards' reports, isn't in FormFav cards.
