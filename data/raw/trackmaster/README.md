Put TrackMaster Plus XML files (e.g. `fl20261020plusXML.xml`) here for local
pipeline runs. Everything in this folder except this README is git-ignored,
because TrackMaster data is licensed and must not be republished.

To predict a TrackMaster card without installing anything, load the file on
the dashboard's **Enter a race** tab instead. It's processed in your browser
and never uploaded anywhere.
