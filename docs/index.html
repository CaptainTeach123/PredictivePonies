How it works

  1. Horse racing XML files — race entries, past performances and historical results (ponies/xml_io.py).
  2. Python data processing — point-in-time features: speed figures, recent form, distance/surface/condition fit, jockey and trainer win rates (ponies/features.py).
  3. Machine-learning model — two models, each tested on later races it never saw (ponies/evaluate.py). The speed-figure model predicts each horse's next speed figure from its own past starts and simulates the race (ponies/figure_model.py). The conditional logit learns from complete past races (ponies/model.py). Whichever backtests better is used.
  4. Race prediction dashboard — this page, reading JSON from docs/data/ (ponies/pipeline.py). The Enter a race tab runs the same Python code in your browser with Pyodide (ponies/browser.py).

Every modelling assumption has an ID like [A-03] listed in ASSUMPTIONS.md. Source: GitHub repository.
