# XML data schema

Put files in these folders (any filename ending in `.xml`):

| Folder | Contents | Used for |
|--------|----------|----------|
| `data/raw/results/` | Historical result charts, one file per track and date | Training, backtesting, form history |
| `data/raw/past_performances/` | Per-horse past-performance lines | Extra form history for races not in `results/` |
| `data/raw/entries/` | Upcoming race cards (no outcomes) | Live predictions on the dashboard |

Files whose name starts with `SYNTHETIC_` are generated by
`scripts/make_sample_data.py`. While any are present, the dashboard shows a
"synthetic data" banner. Delete them once you have real data.

**Using a vendor's own XML (Equibase, TrackMaster, Brisnet and so on):** either
convert it into the layout below, or add a parser in `ponies/xml_io.py` that
returns rows with the `START_COLUMNS` fields. Nothing after stage 1 depends on
the XML layout.

## Results: `data/raw/results/*.xml`

```xml
<results track="SAR" date="2026-08-01">                 <!-- date: YYYY-MM-DD -->
  <race number="1" distance_furlongs="6" surface="dirt" condition="fast"
        class="claiming" purse="25000">
    <starter program="1" post_position="1"
             horse_id="H123" horse_name="Example Horse" age="4" sex="G" weight_lbs="120"
             jockey_id="J9" jockey_name="A. Rider" trainer_id="T4" trainer_name="B. Trainer"
             morning_line="5-2" final_odds="2.8-1"
             finish_position="1" speed_figure="92" beaten_lengths="0"/>
    <starter ... scratched="true"/>                     <!-- dropped [A-21] -->
  </race>
</results>
```

## Entries: `data/raw/entries/*.xml`

These use the same layout with `<entries>` as the root. `final_odds`,
`finish_position`, `speed_figure` and `beaten_lengths` are left out.

## Past performances: `data/raw/past_performances/*.xml`

```xml
<past_performances generated="2026-08-01">
  <horse id="H123" name="Example Horse">
    <line date="2026-07-04" track="BEL" race_number="5" distance_furlongs="6.5"
          surface="dirt" condition="sloppy" class="allowance" purse="60000" field_size="9"
          post_position="3" weight_lbs="122" jockey_id="J9" trainer_id="T4"
          final_odds="4-1" finish_position="2" speed_figure="88" beaten_lengths="1.25"/>
  </horse>
</past_performances>
```

## Field rules

* **IDs** (`horse_id`, `jockey_id`, `trainer_id`) must be stable across all files. Form history and de-duplication [A-20] rely on them.
* **Odds** use the US odds-to-one format: `5-2`, `5/2`, `7` (meaning 7-1) or `EVEN`. See `ponies/odds.py`.
* **Distances** are in furlongs (1 mile = 8 furlongs).
* **surface**: `dirt`, `turf` or `synthetic`. **condition**: free text, which [A-05] maps to wet or dry. Both are case-insensitive.
* **Missing attributes** are allowed. They become `NaN` and are handled by [A-07], [A-17] and [A-18].
* `race_id` is derived as `TRACK-YYYY-MM-DD-RACENUMBER`.
